# Public observation journal and acknowledged tailer

The approved-staging CLI is still inactive. When separately approved, it now passes its persisted process runId to the existing bounded local journal. Each complete NDJSON record is `{version:1,runId,epoch,sequence,observation}`. Epoch is the observation's per-symbol feedEpoch; it is not globally monotonic across symbols. Sequence starts at one per strictly newer run and increases on fsynced writes. Existing raw legacy rows cannot be silently upgraded: the new envelope writer/tailer rejects them for operator review. The raw helper mode remains only for backward-compatible local fixtures; the actual CLI uses enveloped mode.

`PublicMarketTailer` reads only exact segment names from one trusted private directory. It bounds segment count, bytes read, records and row size. A cursor includes runId, last record epoch/sequence, segment number, byte offset after its newline, and a semantic SHA-256 envelope hash. Hashes sort object keys recursively; physical newline/offset checks independently verify file anchoring. Decoded JSON must be valid UTF-8. No record content is included in parse errors.

`read()` proposes a stable batch without advancing the acknowledged cursor. Repeat reads return the pending batch. The persistence owner must atomically commit its projection and batch.to cursor before calling `acknowledge(batchId)`. The tailer does not write an independent source checkpoint that could acknowledge uncommitted data. Restart supplies the sink's durable acknowledged cursor. Lost COMMIT responses require sink reconciliation; do not invent a replacement cursor or skip a pending batch.

Cursor anchoring detects mutation/truncation; missing retained segments, numeric segment gaps, sequence gaps/rewinds and incomplete sealed segments fail closed. A partial current last line remains unacknowledged and can be read only after a complete newline arrives. The writer separately refuses reopening an incomplete tail; restoring/truncating corrupt writer state remains a separately reviewed operator action, never silent evidence deletion. Ring retention can overtake the consumer; this is a visible gap requiring rebootstrap approval, not an exactly-once archival transport. With no prior cursor, missing segment zero is rejected rather than assuming that a retained suffix is complete.

Six offline tests exercise the real journal envelopes, duplicate proposals/ack conflicts, durable cursor restart, new process sequence, varying per-symbol epochs, legacy refusal, partial completion, rotation/retention gaps, sealed partial rows, anchor corruption/truncation, oversized rows, sequence gaps and semantic hash binding. All filesystem tests use disposable local fixtures. No database connection, remote write, notifications, service, credential or exchange order is created. The consumer's private directory and source identity must be separately protected at deployment; source hashes alone are not authentication against an attacker controlling the journal.
